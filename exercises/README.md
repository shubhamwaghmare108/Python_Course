# Exercises

Practice is organized into **100 progressive labs**:

- **Beginner:** Labs 1–35 — Python syntax, collections, conditions, loops, and problem solving
- **Intermediate:** Labs 36–65 — functions, OOP, files, exceptions, and logging
- **Advanced:** Labs 66–100 — NumPy, pandas, visualization, SQL/PyMySQL, EDA, and PySpark
- **Projects:** Four larger deliverables that combine the course modules

## How to use a lab

Each lab now includes:

1. **Objective** — the exact skill being practiced
2. **Task** — a reproducible scenario and input/data guidance
3. **Expected evidence** — output/results that another student can verify
4. **Acceptance criteria** — normal, boundary, and invalid/empty cases where applicable
5. **Challenge** — one extension beyond the core requirement
6. **Interview question** — a concept check for review

Use the course rubric and progression guide in CURRICULUM.md.
