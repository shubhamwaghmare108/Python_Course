# Lab — Variables & Types

## Objective

Create variables for a student's name, age, percentage, and enrollment status. Print each value and its type. Then convert a numeric string to an integer.

## Requirements

- Write clean, readable Python.
- Do not hard-code results.
- Add at least one validation or edge-case check.

## Deliverable

Submit a Python file or notebook containing the solution and a short explanation of your approach.

## Extension

Add one additional feature that was not explicitly requested and explain why it is useful.
