# Project 01 — Python CLI

## Goal
Build a small command-line application that solves a real problem using functions, modules, validation, files, and exceptions.

## Minimum requirements
- At least 3 modules with clear responsibilities.
- Command-line input or menu-driven interaction.
- Input validation and user-friendly errors.
- Persistent data using JSON or CSV.
- At least 5 automated tests.
- README with setup, usage, sample session, and design decisions.

## Acceptance criteria
A user can install the project, run it from a clean environment, perform the main workflow, recover from invalid input, and reproduce the documented sample output.

## Stretch
Add logging, configuration through environment variables, and one additional command.
