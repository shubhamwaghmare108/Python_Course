# Project 02 — Data Analysis

## Goal
Build a reproducible analysis of a real dataset using Pandas, NumPy, and visualization.

## Minimum requirements
- Document the business/question being investigated.
- Load data without machine-specific paths.
- Profile columns, missing values, duplicates, and data types.
- Clean and justify important transformations.
- Produce at least 3 meaningful visualizations.
- Calculate at least 5 useful metrics or grouped summaries.
- Write 5–8 evidence-based findings.

## Acceptance criteria
Another student can run the notebook from a clean environment and reproduce the tables, charts, and conclusions.

## Stretch
Add a reusable analysis function, a second dataset, or an interactive Plotly view.
