# Project 03 — Database Application

## Goal
Build a Python application that reads and writes relational data safely.

## Minimum requirements
- Use environment variables for database configuration.
- Use parameterized SQL for user-provided values.
- Implement at least 3 read queries and 2 write operations.
- Demonstrate commit and rollback behavior.
- Handle connection and query errors.
- Include schema/query documentation and tests.

## Acceptance criteria
The application never requires credentials in source code and user input is never concatenated directly into SQL.

## Stretch
Add SQLAlchemy, connection pooling, pagination, or a small reporting layer.
