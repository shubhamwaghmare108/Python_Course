# Project 04 — End-to-End

## Goal
Combine ingestion, cleaning, database operations, analysis, visualization, logging, testing, and documentation into one reproducible project.

## Required pipeline
Ingest → Validate → Clean → Store → Analyze → Visualize → Report

## Minimum requirements
- Clear problem statement and architecture diagram.
- Reproducible environment setup.
- At least one persistent data store.
- Data validation and error handling.
- Structured logging for important pipeline events.
- Automated tests for core logic.
- At least 3 analytical outputs and 3 visualizations.
- Final README describing assumptions, limitations, and results.

## Acceptance criteria
A reviewer can clone the project, configure environment variables, run the documented commands, and reproduce the principal outputs.

## Stretch
Add PySpark for a larger transformation stage, CI checks, or a small API/dashboard.
