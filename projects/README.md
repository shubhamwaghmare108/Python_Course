# Projects

Projects convert the course modules into portfolio-ready deliverables.

## Project progression

| Project | Prerequisites | Main skills | Deliverables |
|---|---|---|---|
| 01 Python CLI | Modules 1–8 | Functions, modules, validation, files, exceptions | Source code, README, tests, sample run |
| 02 Data Analysis | NumPy/Pandas/visualization | Cleaning, analysis, charts, interpretation | Notebook, cleaned data, charts, insight report |
| 03 Database Application | SQL/PyMySQL | Schema usage, parameterized SQL, transactions | Application, SQL notes, `.env.example`, tests |
| 04 End-to-End | Entire course | Ingestion → analysis → persistence → reporting | Source, tests, documentation, architecture diagram, demo |

## Project quality gate

- Clear problem statement.
- Reproducible setup instructions.
- Repository-relative paths.
- `.env.example` instead of secrets.
- Meaningful error handling.
- Tests for important behavior.
- Sample input/data.
- Expected output or screenshots.
- README with architecture and usage.
- Limitations and future improvements.

## Suggested evaluation

| Area | Weight |
|---|---:|
| Functional correctness | 30% |
| Code/design quality | 20% |
| Testing and reliability | 15% |
| Data/SQL correctness | 15% |
| Documentation | 10% |
| Presentation/demo | 10% |
| **Total** | **100%** |
